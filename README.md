# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Lakukan clone pada repository ini.
2. Buka terminal dan jalankan `composer install`.
3. Salin file `.env.example` menjadi `.env` dan sesuaikan koneksi database.
4. Jalankan `php artisan key:generate`.
5. Jalankan `php artisan migrate`.
